# PYRO Detector - Issue Tracker

## Issue Tracking System

This document tracks all issues found during UA testing.

## Issue Status

- **Open**: Issue identified, not yet fixed
- **In Progress**: Issue being worked on
- **Fixed**: Issue resolved, awaiting verification
- **Verified**: Issue fixed and verified
- **Won't Fix**: Issue will not be fixed (with reason)
- **Duplicate**: Duplicate of another issue

## Issue Categories

- **Critical**: System crashes, data loss, security vulnerabilities
- **High**: Major functionality broken, performance degradation
- **Medium**: Minor functionality issues, UI problems
- **Low**: Cosmetic issues, minor improvements
